Wild hand waving / executable follow-up

Re-inventing a neuron, badly enough to test it.

The informal picture is simple: persistent input statistics meet a branching physical object; local activity changes that object; the changed object changes what can be learned next.

The video can wave its hands. This repository cannot. The animation below is a conceptual map, not evidence and not a literal biophysical neuron. Evidence starts at the gates.

The falsification ladder

What each gate actually establishes.

Gate 0

Can Oja recover a known principal direction?

Yes: cosine alignment ≈ 0.995595.

Does not establish ICA, a full PCA basis, or dendritic biology.

Gate 1

Where does two-layer computation enter?

Linear branches collapse exactly; branch nonlinearity creates the shallow-network form.

This is algebra, not a novelty claim about neurons.

Gate 2

Can local spectral coordinates become useful only after nonlinearity?

Variance-only task: raw linear 0.494, identity branches 0.5078, squared branches 0.935.

A deliberately constructed second-order task, not a general benchmark.

Gate 3

What does “mode purification” mean safely?

Relative slow/fast ratio reaches 36.60× at t=20.

All absolute modes may still decay; this is not active sharpening by itself.

Gate 4

Can physical recurrence reshape the statistics seen by Oja?

Constructive alignment: 0.72218 → 0.99901.

An existence test with a hand-built two-state recurrence.

Gate 5

Can an alignment-blind local rule reshape a branched substrate?

Held-out mean: frozen 0.78218 → local 0.90019; shuffled 0.75922.

One topology, one rule, one seed. Not biological validation.

Gate 5B

What physically changed in Gate 5?

Basis-only diagnostic 0.89240; eigenvalue-only 0.80109; full 0.90019.

Counterfactual decomposition, not proof that biological dendrites rotate eigenbases this way.

Gate 6

Does the same frozen rule survive many worlds?

Predeclared 24-world robustness suite: topology, ports, sensors, covariance geometry and seed vary; losses are retained.

The receipt is authoritative; no failed world will be tuned away.

Next hypothesis · not a result

AIS / output boundary as load-matching adaptation

The informal video asks whether a changing dendritic load and an adaptive action-initial-segment boundary form a second slow feedback loop. That is a future hypothesis. AnttisNeuron currently models neither AIS geometry nor conductance-based spike initiation. It belongs after robustness, not inside the evidence already earned.
