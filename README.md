# AnttisNeuron

> Wheel re-invented, but with the axle instrumented.

**AnttisNeuron** is a small falsifiable study of one specific synthesis:

a local Oja learner selects a statistical input mode, stable branched dynamics filter those statistics through time, branch-local nonlinearities provide computational subunits, and slow local structural changes can in turn alter the physical operator that the learner observes.

The central point is not that a biological neuron can look like a two-layer network—that is prior art. The useful question here is narrower:

> **When can local statistics and a physical branched operator reshape one another, and when does that idea fail?**

The repository separates exact algebra from simulation and keeps the attractive statistical↔physical eigenmode idea falsifiable.

## What is established, and what is being tested here?

| Statement | Status |
|---|---|
| Oja's rule can converge toward a leading covariance eigenvector | Prior work; executable sanity check here |
| Nonlinear dendritic subunits can make a pyramidal neuron resemble a two-layer network | Prior work (Poirazi et al., 2003) |
| Active dendrites can support linearly nonseparable single-neuron computation | Prior work (e.g. Gidon et al., 2020) |
| Human-neuron functional complexity depends strongly on dendritic morphology and nonlinear synaptic integration | Recent modeling result (Aizenbud et al., 2026) |
| AIS composition/position affect excitability and can change with physiological conditions | Prior biological work summarized by Leterrier (2018) |
| If branch nonlinearities are removed, static branches collapse to one linear filter | Exact identity tested here |
| With branch nonlinearities, the static abstraction is exactly a one-hidden-layer network | Exact identity tested here |
| With `psi(z)=z^2`, the neuron is a quadratic classifier `x^T Q x` | Exact identity tested here |
| Oja-learned local modes + square branch responses expose a variance-only task that linear controls cannot | Synthetic result here |
| Differential physical decay can increase **relative** slow-mode purity | Exact/simulated result here |
| Recurrent branch dynamics can reshape observed statistics toward a physical slow mode | Constructive existence result here |
| Alignment-blind local conductance adaptation can improve held-out statistical↔physical mode alignment in one synthetic branched cable | Gate 5 synthetic result here |
| The Gate-5 gain is mainly associated with physical-basis reorientation rather than eigenvalue change | Gate 5B diagnostic result here |
| The unchanged Gate-5 local rule robustly improves arbitrary branched worlds | **Not supported by Gate 6** |
| Real dendrites spontaneously co-adapt statistical and physical eigenmodes | **Not established** |

## Model

For branch `j`, local input is `x_j(t)` and Oja learning gives a direction `w_j`:

```text
y_j(t) = w_j^T x_j(t)
Δw_j = η y_j (x_j - y_j w_j)
```

A minimal physical branch is a stable linear state-space system:

```text
d_j(t+1) = A_j d_j(t) + b_j y_j(t)
r_j(t)   = c_j^T d_j(t)
q_j(t)   = ψ_j(r_j(t))
```

The soma-like readout pools branch outputs:

```text
v(t) = Σ_j a_j q_j(t) + b
```

In the static effective-filter abstraction, with branch filters `m_j`,

```text
v = Σ_j a_j ψ(m_j^T x) + b.
```

If `ψ` is identity, everything collapses to a single linear filter. If `ψ(z)=z²`,

```text
v - b = Σ_j a_j (m_j^T x)² = x^T Q x,
Q = Σ_j a_j m_j m_j^T.
```

### Gate 5 — one real synthetic success

Gate 5 uses an **11-node branched weighted graph cable** with four distal input ports and only four observed node voltages. Its topology defines physical eigenmodes, but the structural rule never receives those modes, the Oja vector, an alignment score, labels, or held-out performance.

Each edge sees only its own mean squared voltage difference. The strongest control receives the **exact same per-phase update-value multiset** as the local rule, shuffled onto the wrong edges; the measured multiset mismatch is `0.0`.

Across five held-out covariance rotations:

```text
frozen structure          0.782185
shuffled local credit     0.759219
correct local credit      0.900191
```

This establishes a synthetic case in which local, alignment-blind structural change helps. It does not establish a general law.

### Gate 5B — what actually moved?

Gate 5B decomposes the already-produced frozen and adapted operators. Two diagnostic counterfactuals keep either the frozen eigenvectors with adapted eigenvalues, or adapted eigenvectors with frozen eigenvalues:

```text
frozen                    0.782185
adapted eigenvalues only  0.801087
adapted eigenvectors only 0.892401
fully adapted             0.900191
```

Most of the Gate-5 gain therefore tracks **reorientation of the physical basis**, not merely a slower decay constant. These hybrid operators are diagnostic symmetric matrices, not claimed realizable positive-conductance dendrites.

### Gate 6 — then the generalization attempt mostly fails

Gate 6 freezes the Gate-5 rule and hyperparameters, then evaluates **24 deterministic worlds** with different tree topology, input ports, sensor placement, covariance geometry, and seeds. The exact-multiset shuffled-credit control and common tapes are retained.

A numerical audit exposed a near-degenerate-eigenspace problem in an earlier individual-eigenvector score. The committed Gate-6 metric therefore uses the normalized projection of the Oja direction into the span of the **three slowest visible non-uniform physical modes**. The score is invariant to arbitrary sign, permutation, or basis rotation inside that subspace.

The corrected result is close to a null overall:

```text
local beats frozen        11 / 24 worlds
mean local - frozen       +0.000498
median local - frozen     -0.000118
local beats shuffled       9 / 24 worlds
mean local - shuffled     -0.003074
```

There are nevertheless large world-specific effects: some worlds improve strongly while others degrade strongly. Because a 3-D subspace inside the 4-D sensor space naturally gives high absolute projection scores, **Gate 6 should be read from within-world deltas and their distribution, not from the absolute ~0.93 mean alignment**.

So Gate 6 narrows the claim:

> The Gate-5 mechanism can occur, but this particular local rule is not a topology-independent organizing principle.

That negative generalization result is kept rather than tuned away.

## Interpretation rules

1. **Two-layer neuron is prior art.** AnttisNeuron does not claim otherwise.
2. **Oja is PCA-like, not ICA.** One Oja unit learns one dominant direction; identical independent units do not magically produce the full PCA basis.
3. **Passive/linear branch dynamics do not create nonlinear computational depth.** Without local nonlinearity the static model collapses.
4. **Mode purification means relative differential decay here.** The slow component can dominate relative to faster components while all absolute amplitudes decay.
5. **Statistical mode != physical mode by default.** Alignment requires coupling; Gate 4 constructs one such coupling.
6. **Gate 5 is structural but still synthetic.** Gate 5B identifies basis reorientation as the dominant diagnostic component in that construction.
7. **Gate 6 is a generalization failure, not a software failure.** The unchanged rule is approximately neutral versus frozen overall and does not beat shuffled credit overall.
8. **Subspaces, not arbitrary eigenvector labels, are the stable object near degeneracy.** Gate 6 therefore uses a basis-invariant projection score.
9. **The NMDA activation in code is a toy supralinear surrogate.** It is not a conductance-based NMDA receptor model.
10. **AIS/load adaptation is future work.** The current model uses a simple pooled readout and does not model axonal excitability.

## Biological anchors, not validation

The biological papers motivate the next questions without validating this graph rule. Aizenbud et al. (2026) report that dendritic morphology and nonlinear synaptic integration jointly shape modeled single-neuron functional complexity; notably, total dendritic area and bifurcation-related geometry carry more information than branch count alone. Leterrier (2018) reviews the AIS as a plastic determinant of neuronal excitability whose position and composition adapt to physiological conditions.

That makes two future abstractions worth testing separately: **which geometric/electrical-load features distinguish Gate-6 successes from failures**, and whether a slow AIS-like output boundary can compensate for changes in dendritic load. Neither is yet an established result in this repository.
