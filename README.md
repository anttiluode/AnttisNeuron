# AnttisNeuron

> Wheel re-invented, but with the axle instrumented.

**AnttisNeuron** is a small falsifiable study of one specific synthesis:

a local Oja learner selects a statistical input mode, a stable branch dynamics filters that mode through time, a branch-local nonlinearity turns branches into computational subunits, and a soma-like readout pools those subunits.

The central point is not that a biological neuron can look like a two-layer network—that is prior art. The useful question here is narrower:

> **What changes when the hidden units are not arbitrary learned filters, but locally learned spectral modes passing through physical branch dynamics?**

The repository separates exact algebra from simulation and keeps the attractive statistical↔physical eigenmode idea falsifiable.

## What is established, and what is being tested here?

| Statement | Status |
|---|---|
| Oja's rule can converge toward a leading covariance eigenvector | Prior work; executable sanity check here |
| Nonlinear dendritic subunits can make a pyramidal neuron resemble a two-layer network | Prior work (Poirazi et al., 2003) |
| Active dendrites can support linearly nonseparable single-neuron computation | Prior work (e.g. Gidon et al., 2020) |
| If branch nonlinearities are removed, static branches collapse to one linear filter | Exact identity tested here |
| With branch nonlinearities, the static abstraction is exactly a one-hidden-layer network | Exact identity tested here |
| With `psi(z)=z^2`, the neuron is a quadratic classifier `x^T Q x` | Exact identity tested here |
| Oja-learned local modes + square branch responses expose a variance-only task that linear controls cannot | Synthetic result here |
| Differential physical decay can increase **relative** slow-mode purity | Exact/simulated result here |
| Recurrent branch dynamics can reshape observed statistics toward a physical slow mode | Constructive existence result here |
| Alignment-blind local conductance adaptation can improve held-out statistical↔physical mode alignment in the synthetic branched cable | Gate 5 synthetic result here |
| Real dendrites spontaneously co-adapt statistical and physical eigenmodes | **Not established** |

## Model

For branch `j`, local input is `x_j(t)` and Oja learning gives a direction `w_j`:

```text
y_j(t) = w_j^T x_j(t)
Δw_j = η y_j (x_j - y_j w_j)
```

A minimal physical branch is a stable linear state-space system:

```text
d_j(t+1) = A_j d_j(t) + b_j y_j(t)
r_j(t)   = c_j^T d_j(t)
q_j(t)   = ψ_j(r_j(t))
```

The soma-like readout pools branch outputs:

```text
v(t) = Σ_j a_j q_j(t) + b
```

In the static effective-filter abstraction, with branch filters `m_j`,

```text
v = Σ_j a_j ψ(m_j^T x) + b.
```

That formula is where the controls become sharp. If `ψ` is identity, everything collapses to a single linear filter. If `ψ(z)=z²`,

```text
v - b = Σ_j a_j (m_j^T x)² = x^T Q x,
Q = Σ_j a_j m_j m_j^T.
```

### What Gate 2 actually says

The classes have approximately zero mean and differ in energy along two orthogonal modes. A linear readout on raw input has no stable sign cue, and linear branch responses do not help. Two independently Oja-learned local filters recover those modes, and squaring their responses makes the variance difference linearly readable at the soma.

This is a deliberately small demonstration of:

```text
spectral learning -> local nonlinear feature -> simple pooled decision
```

It is not a claim that Oja learning solves arbitrary nonlinear tasks.

### What Gate 4 actually says

Gate 4 is a constructive existence test. External statistics begin with their principal direction halfway between two input-visible physical modes. A stable recurrent branch has eigenvalues `0.97` and `0.65`; observing its recurrent state preferentially amplifies the slow physical mode. Oja then follows the statistics produced by that dynamics.

The memoryless control returns to the fixed alignment. So the change is caused by the recurrent physical filter in this constructed model.

This is **not** yet self-organizing morphology, biological validation, or a proof that statistical and dendritic eigenmodes generally align.

### What Gate 5 adds

Gate 5 removes the hand-built two-state spectral target. The substrate is an **11-node branched weighted graph cable** with four distal input ports and only four observed node voltages. Its fixed topology defines physical eigenmodes, but the structural learning rule never receives those modes, the Oja vector, an alignment score, class labels, or a held-out score.

Only edge conductances change. Each edge sees its own mean squared voltage difference and applies the same slow homeostatic rule. Total mean conductance is renormalized after every structural step, preventing the trivial solution of scaling every edge together.

The strongest control gets the **exact same per-phase update-value multiset** as the local rule, but the values are shuffled onto the wrong edges. The measured multiset mismatch is `0.0`. A uniform-control update leaves relative conductances unchanged and numerically reproduces the frozen result.

Across five covariance rotations that were not used for structural adaptation:

```text
frozen structure          0.782185 mean alignment
shuffled local credit     0.759219
correct local credit      0.900191
```

The adaptive minimum across held-out environments also rises from `0.606365` to `0.839369`. The slowest non-uniform physical eigenvalue moves from `0.985983` to `0.988155`, and local edge activity predicts the resulting conductance changes with correlation `0.976240`.

That is a stronger result than Gate 4 because no global spectral objective tells the structure what mode to create. But it remains a **synthetic graph-diffusion experiment**. It does not show that biological dendrites use this exact plasticity rule, and it does not establish a general theorem that local homeostasis optimizes statistical↔physical eigenmode alignment.

## Interpretation rules

1. **Two-layer neuron is prior art.** AnttisNeuron does not claim otherwise.
2. **Oja is PCA-like, not ICA.** One Oja unit learns one dominant direction; identical independent units do not magically produce the full PCA basis.
3. **Passive/linear branch dynamics do not create nonlinear computational depth.** Without local nonlinearity the static model collapses.
4. **Mode purification means relative differential decay here.** The slow component can dominate relative to faster components while all absolute amplitudes decay.
5. **Statistical mode != physical mode by default.** Alignment requires coupling; Gate 4 constructs one such coupling.
6. **Gate 5 is structural but still synthetic.** Its local rule is alignment-blind, yet the substrate is a graph diffusion model rather than a conductance-based dendrite.
7. **The NMDA activation in code is a toy supralinear surrogate.** It is not a conductance-based NMDA receptor model.
8. **AIS/load adaptation is future work.** The current model uses a simple pooled readout and does not model axonal excitability.
